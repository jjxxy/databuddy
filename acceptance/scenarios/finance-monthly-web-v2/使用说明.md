# 财经月结多来源综合测试包

这是一套虚构业务测试，包含一个本机模拟业务网站、分页网页、下载附件、分页 JSON 接口、复杂 Excel、需求描述和独立标准答案。全部数据均为合成资料。订单和退款沿用上一版数据，本版增加了更复杂的 Excel、网页和接口取数，以及独立总账对账。

1. 先阅读 `测试步骤.md`，按照说明双击 `web/start.cmd` 启动模拟网站。网站仅监听本机，关闭启动窗口即可停止。
2. 在运行网站的电脑浏览器打开 `http://127.0.0.1:8765/`，检查网页分页、附件和接口；将 `inputs` 中的两份复杂 Excel 上传到 Nexus WorkStudio，复制 `需求描述.md` 提交。
3. 查看系统能否自动取数、核对分页、处理非规范表格和解释对账差异，再要求它生成 Excel、经营报告和汇报 PPT。
4. 测试结束后才打开 `answer`：这里是独立复算答案，不要上传或提供给被测试系统。

本机地址能否由 Nexus WorkStudio 访问取决于部署位置和现有网络策略；云端服务中的 `127.0.0.1` 并不是你自己的电脑。API 连接器默认拒绝回环地址，管理员需在隔离测试服务中明确允许后才能测试；云浏览器默认也禁止访问回环。人工下载再上传可以继续验证财务加工，但不能视为自动抓取和接口访问成功。详细限制及替代步骤见 `测试步骤.md`。
