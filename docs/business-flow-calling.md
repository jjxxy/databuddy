# 调用已采用的业务流程

业务流程调用由已授权的 Atlas 服务执行；请求必须包含项目、流程、已采用版本摘要、参数对象和请求编号。提交成功只表示已入队，需通过运行记录确认状态及实际输出。服务端会校验权限、版本、参数、运行时锁和来源固定信息。

可在服务环境中使用 `python -m agent_service.business_flow_client` 调用。将服务地址和访问凭证分别保存在 `NEXUS_URL`、`NEXUS_TOKEN` 环境变量中，不要写进参数文件或代码仓。远程服务必须使用 HTTPS，本机回环地址可以使用 HTTP。参数文件是 UTF-8 JSON 对象，金额等小数应按流程声明使用十进制字符串；文件型参数使用服务要求的来源 ID、版本和哈希。

```text
python -m agent_service.business_flow_client --project PROJECT_ID --flow FLOW_ID --digest VERSION_SHA256 --request-id YOUR_STABLE_REQUEST_ID --inputs inputs.json
```

每次新业务调用使用新的请求编号；如果网络中断导致不能确认是否已收到，重试时必须使用**相同编号、相同版本和相同参数**，不能随意换编号。调用会返回运行编号，实际成功、失败、人工复核和结果需要查询对应运行记录。服务不可用、版本不一致或来源版本变化时不得假定已执行。

流程导出包的入口绑定所选版本摘要，只允许调用已经采用的同一版本；如果该版本尚未采用或已被其他版本替换，服务会拒绝。旧版入口导出时只接受预期的历史模板，并重新生成受控入口，不执行任意 Git 文件。
