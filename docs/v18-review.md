# v0.18 新增工作空间能力：独立复核与上线边界

复核日期：2026-10-23。本文依据当前源码、专项回归和下列官方公开文档，不代表已经在客户电脑、企业身份系统、实际模型或报表网站完成生产验收。部署步骤见 [本地模式](../LOCAL-MODE.md)，既有23项需求对应见 [业务工作空间](../BUSINESS-WORKSPACE.md)，追加验收见 [v18工作空间验收](../acceptance/finance_monthly/V18-WORKSPACE-ACCEPTANCE.md)。

## 产品判断

本产品应保持“财经业务用户持续工作的个人数据空间”定位：对话负责提出目标和修改做法，固定方案和确定性执行负责计算，来源、版本、控制数和人工核阅负责判断是否可信。多文件、Skill、MCP和记忆改善连续工作，不能自动解决来源不完整、口径错误、权限缺失或模型判断失误。

“AI生成代码，所以数字必然准确”这个前提不成立。错误的表格范围、期间、币种、关联基数或累计/当期含义，会被正确运行的代码稳定放大。正常样本必须能正确处理；异常样本应有依据地停止。二者不能混成一个“安全成功率”。

页面“整理上下文”生成Atlas的持久工作索引。它与OpenCode模型会话摘要是两个机制，不能将前者的成功回执描述为模型已经完成压缩。OpenCode的压缩仍受所选模型、上下文大小、预算和服务可用性约束；HTTP受理不等于完成。

同名或相同字节的不同上传可保留为不同来源；按请求编号重试保留同一次上传身份。不能因为内容一样就推断两份文件应在业务上去重，也不能重复计算它们。来源版本变动后应明确重绑和重跑，保留旧原件与旧结果。

以下编号对应用户原始23项需求，不是新的“全部通过”认证。

| 需求编号 | 可以依赖的实现 | 上线时还要验证 |
| --- | --- | --- |
| 1—3：网页、明细、复杂底稿 | 有界取数、全量交接、来源快照；页签、区域、多级表头与合并坐标证据 | 实际网站的iframe/登录/筛选；脱敏真实底稿；默认单文件25MB、来源100000行等预算。超限失败不能截断后称完整 |

AI可以降低用户调试负担，但不应将尚未核实的数值、自动猜测的映射或不完整结果交给用户当作正式结论。

## 个人资源与共享项目的区别

个人Skill安装、个人MCP配置和个人偏好绑定服务端验证的身份。OIDC主体与发行方共同派生身份；客户端不能提交`actor_id`冒充他人；任务执行恢复其发起者身份。共享访问口令只代表一个共同使用者，换浏览器不会产生另一个个人账户。

当前实例的项目、资料、会话和成果仍沿用共同拥有的工作空间范围，尚未实现互不信任用户之间完整的项目/资产隔离。个人MCP的密钥和启停配置不向其他身份开放，**但通过它在项目中取得的数据、任务记录和成果会进入该项目的共享范围**，也可能进入后续模型上下文。加密保存凭据与隔离结果是两件事；结果下载之后也不能远程收回。

如需集中服务彼此不信任的个人、部门或租户，必须另行验收项目/资产访问控制、队列和存储隔离、连接数据的可再分享权限。没有这些措施时宜采用独立部署，不能仅凭新增OIDC个人偏好就宣称多租户隔离。

## 本地文件与代码执行的实际权限

本次核对的默认路径如下：

| 路径 | 实际约束 |
| --- | --- |
| OpenCode原生工具 | 默认删除原生shell、文件系统、任意MCP和子Agent工具，仅通过Atlas受控工具执行业务操作 |
| Agent写入`.py`/`.sql` | 作为项目文本保存和版本管理；写文件本身不执行代码 |
| 类型工作流SQL | 只查询明确输入表；AST/函数允许列表；DuckDB禁外部访问、扩展和文件读取函数，并有时间/行数预算 |
| 任意Python | 默认工具不可用。只有管理员另配独立远端隔离执行器后可用；只发送指定的项目文本文件，不挂载宿主目录，也不发送数据库/模型环境凭据。声明`microvm`或`gvisor`及返回回执仍需独立部署验收 |
| 本地浏览/导入和项目文本helper | 相对路径、目录描述符、不跟随链接、普通文件和大小检查；排除隐藏目录及常见凭据；导入前后核对文件身份和修改信息 |
| 本地stdio MCP | 只启动管理员预置的已安装命令模板，用户明确启用，模型不能添加任意命令。清理继承环境、限时、限消息体积并回收进程；这不是操作系统文件或网络沙箱 |

因此，**默认没有允许应用生成的任意Python直接读取整个挂载文件夹的执行入口**。不过，`compose.local.yaml`确实把用户选择的整个目录读写挂载到同一个应用容器；应用与可信stdio进程使用运行UID，stdio的工作目录是该目录。它们在操作系统层面可以访问该UID有权限的挂载内容，包括`.atlas`等内部目录，而不受“页面只勾选了两个文件”的限制。删去子进程环境中的密钥不会阻止进程读取同UID可读的凭据文件。

Docker默认未挂载的电脑目录不会因本模式自动可见；Docker容器也不等于按任务/按文件的独立沙箱。该包没有给每次本地程序运行建立独立microVM、文件挂载允许列表或OS出站防火墙。Git、本机同步软件和用户主动运行的程序也属于可信电脑权限边界，不能保证抵御恶意宿主程序或所有目录竞态。

本地代码在`.atlas`之外，旧format2应用备份/恢复不支持此布局，现已明确拒绝，避免遗漏代码却报告备份成功。本地需先停止服务，再备份整个所选目录（含隐藏的`.atlas`、代码和成果），另存部署配置；成果导出不能代替完整备份。

选择专门的业务目录、只安装可信模板，是当前模式的操作要求。若以后开放任意本地代码，应先实现独立执行身份、最小文件挂载、只读输入、无网络执行、资源限额和结果回收；不应直接打开OpenCode shell来绕过现有工具限制。

## 本地、仅本地连接和真正离线

1. **本地存储**：文件导入快照、会话和成果保存在所选目录；默认仍可连接管理员提供的云端LLM。
2. **仅本地连接策略**：`ATLAS_NETWORK_MODE=local_only`限制应用连接到本机或管理员明确允许的私网目标，拒绝公网、元数据链路和混合公网DNS解析。模型上游、API/数据库及MCP等连接也要通过相应检查；浏览器导出、公网推送、远程S3备份停用。自定义stdio模板不在此模式开放，仅保留第一方无网络时钟工具。
3. **真正离线运行**：模型权重与推理服务、Docker镜像、Python/原生依赖、OpenCode固定二进制、Skill文件和所需MCP须全部预先准备。首次构建、安装依赖或下载模型需要的网络不能靠`--offline`消失。所选模型须支持本应用需要的原生工具调用；本地代理地址也不能证明代理背后没有云端转发。

正常数据流是：选中文件→校验并复制到`.atlas`原件快照→解析/固定方案→确定性全量计算与校验→候选/正式结果→报告/导出。模型按授权接收完成任务所需的对话、语义、工具结果和文件片段；`share_data=false`限制内容工具，仍不代表对话文本完全不发送。

应用策略报告`os_network_isolation=false`。它不是所有进程的防火墙：模型客户端与上游进程存在独立DNS解析，可信本地代理或外部程序也可能转发；连接目标检查不能替代OS级出站规则。严格断网要求在实际环境断开互联网并监测出站，在容器/宿主侧实施隔离，还要证明连接失败不会回退云端。

本地模式默认绑定`127.0.0.1`，仍需访问口令。文件夹大小写、中文/空格路径、权限、Windows junction、Docker Desktop共享、网络盘、云同步和休眠恢复应在目标电脑实测。专项测试及脚本检查不等于已在原生Windows/macOS或真实离线模型上验收。

## 上线检查与证据

- 使用真实拟开放模型运行既有财经月报正例与负例；标准答案不给模型。保存每阶段的完整导出、行数、十进制控制数、来源/方案摘要与任务编号。
- 运行追加工作空间用例，特别是多附件部分失败、重启、Skill篡改拒绝、MCP结果未知不自动重发、记忆撤回和压缩后的否定约束。
- 核对长期成本：源快照/版本/日志占用、完整导出、模型重试和压缩费用、电脑睡眠、磁盘不足、恢复所需模型和密钥。未上报用量不等于零成本。
- 本次专项回归曾得到55通过、1项Restic二进制相关跳过，以及新增模块联合88通过；这是当时快照的代码检查记录，不能替代最终整包报告或真实环境验收。后续修改应以发布包的最终日志为准。
- 生产资格遵循既有缺证据阻断流程。未执行的真实站点、模型质量、Docker、OS或故障恢复用例应记为“未验证”，不能记为通过。
