---
name: cloud-work
description: 在获准的云端环境编写和运行代码，检查真实输出并交付可用文件。
---

先明确用户目标、输入资料与需要交付的文件。使用现有项目、历史与可信语义，不要求业务用户调试代码。

1. 用 `work_environment_status` 检查能力。未配置时说明缺少执行环境，不在应用主机运行任意代码。
2. 需要复用的代码先 `write_file` 保存到项目；通过 `run_work_command.project_files` 显式传入。原始附件用本轮明确的 `source_ids` 传入，不经过模型转录二进制或完整数据。
3. 命令在 `/workspace` 执行，原件在 `inputs/<source_id>/<文件名>`。环境无网络、无应用密钥，已有文件检查点自动恢复；不要假设上一次进程仍存在。Python / Node / Bash 与镜像内办公工具可用，不能在主机安装软件。
4. 后台等待由系统处理。收到回执后检查状态、退出码、日志及文件清单；日志是有界片段。失败先检查实际错误并修正，`unknown` 不代表可以盲目重放。
5. 读取真实输出进行检查；需要交付的文件必须 `publish_work_file`，取得真实下载链接后再告诉用户完成。不要把写过代码、生成规格或计划自报完成当作交付。
6. 图片可实际预览，网页可生成离线 Chromium 截图；办公内容提取不等于版式验证。联网浏览与业务系统操作使用已批准的 MCP，外部写入仍需固定参数确认。

财经正式数据加工优先使用已有受验证数据工作流。通用脚本输出是待核对成果，不能替代来源复核、语义确认、精确对账或正式发布；不要声称其数字已经获批。保留执行版本与来源说明，用户后续可继续修改。
